# دليل فريق صمصام · Team Guide

## [افتح الصفحة الرئيسية للدليل](https://ahmads-cell.github.io/semsaam-team-guide/index.html#overview)

![واجهة دليل الفريق](preview-desktop.png)

موقع عام قابل للتصفح دون تسجيل دخول، بموافقة المالك في 9 أكتوبر 2026. يضم 14 قسمًا و15 وثيقة: المنتجات والمواصفات، المنافسون، الأسعار والباقات وحاسبة الربحية، الهوية والتصاميم، البيانات والقرارات ومداخل الفريق. الأسعار والتكاليف والعروض المبدئية وPDF والصور متاحة ضمن الدليل.

هذا مستودع الملفات الجاهزة للنشر. المصدر القابل للتعديل والأرشيف الأصلي محفوظان في مستودع خاص منفصل. الأسعار المقترحة والمنتجات المرشحة للاختبار ليست قرارات بيع أو نتائج مبيعات معتمدة.
